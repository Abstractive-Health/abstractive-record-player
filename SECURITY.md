# Security policy

Please don't report security issues in public issues or pull requests.

Report them privately through GitHub's **Report a vulnerability** button on this repository's
Security tab. Include what you found, how to reproduce it, and its impact. We'll acknowledge it
within a few business days.

Never include real patient information in a report.

## Scope

This repository is a static, frontend-only app. Issues in Abstractive Health's SMART authorization
server or FHIR API can be reported the same way; we'll route them to the right team.
